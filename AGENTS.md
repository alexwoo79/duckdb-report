# Project Instructions

Always load `samber/cc-skills-golang@golang-how-to` before changing Go code.

When editing workflow execution, also load:

- `samber/cc-skills-golang@golang-troubleshooting`
- `samber/cc-skills-golang@golang-testing`

When editing DuckDB access, also load:

- `samber/cc-skills-golang@golang-database`
- `samber/cc-skills-golang@golang-error-handling`

Run `gofmt -w .`, `go test ./...`, and the Vue production build before handing off changes.
